# Local helpers

Use Python 3.10+; helpers have no pip dependencies. Blender rendering requires Blender 4.2+ with EEVEE Next (actual tested versions are recorded in the repository validation report). Media operations require `ffmpeg`, `ffprobe`, libx264; selectable subtitle export uses mov_text. Do not claim compatibility with untested releases. `doctor.py` reports availability, not version compatibility or provider connectivity.

Resolve `SKILL_DIR` to the installed folder; below it is a shell variable set by the agent to the actual path. Quote all paths. Project files live outside this directory.

```sh
python3 "$SKILL_DIR/scripts/doctor.py"
python3 "$SKILL_DIR/scripts/validate_spec.py" scene-v001.json
blender --background --python "$SKILL_DIR/scripts/render_previs.py" -- scene-v001.json previs/v001
python3 "$SKILL_DIR/scripts/media.py" encode 'previs/v001/s01/frame_%04d.png' previs/s01.mp4 --fps 24
python3 "$SKILL_DIR/scripts/media.py" extract previs/s01.mp4 review-frames --every 0.5
python3 "$SKILL_DIR/scripts/media.py" assemble edit.json output/final.mp4
python3 "$SKILL_DIR/scripts/media.py" probe output/final.mp4
```

On macOS the Blender executable may be `/Applications/Blender.app/Contents/MacOS/Blender`. Use the discovered path. Render/extract destinations must not exist; media outputs reject overwrites. Use a new revision for edits. If a command fails after writing partial output, inspect it and choose a new revision rather than pretending it succeeded.

## Scene format v1

See [example-scene.json](../assets/example-scene.json). It is a synthetic jump demo, not a global creative default.

- `version`: 1; `fps`, `width`, `height`: positive integers; dimensions even.
- `shots[]`: unique path-safe `id`, positive integer `frames`, `camera`, `objects`.
- `camera`: `position` and `target`, each XYZ in Blender coordinates (Z up). Fixed within a shot in this starter renderer. For a moving camera, author explicit Blender keyframes in a project-local extension and inspect its render; do not describe a fixed-camera render as a moving-camera previs.
- Objects: unique `id`, `shape` (`cube`, `sphere`, `cylinder`), RGB `color` in 0..1, positive XYZ `scale`, `keys`.
- Each key: shot-local integer `frame`, XYZ `position`, optional XYZ Euler `rotation` in radians. Keys increase from frame 1 through the shot's last frame. Scale is relative to Blender primitives, not absolute dimensions. The renderer uses Blender's default Bezier interpolation: inspect overshoot/contact; add or adjust keys when needed.
- Blender render frames are inclusive 1..N. Edit timeline intervals are zero-based, end-exclusive: a 48-frame first shot is [0,48); the next begins at 48.

The helper saves one .blend and PNG sequence per shot. Encode each sequence, then assemble clips. No audio is generated by the renderer. Proxy parts/complex rigs, lighting design and motion fidelity need project-specific Blender work beyond this starter. Never describe its output as finished character animation.

```sh
python3 "$SKILL_DIR/scripts/validate_spec.py" scene-v002.json --previous scene-v001.json
python3 "$SKILL_DIR/scripts/media.py" compare old.mp4 new.mp4 review-side-by-side.mp4
```

The diff identifies changed or removed shots; global format or shot-order changes mark all affected shots. It does not judge images.

## Edit manifest

Paths are relative to the manifest. Clip order is the edit order, and each duration is a frame count at the output FPS.

```json
{
  "fps": 24, "width": 360, "height": 640,
  "clips": [{"path": "shots/s01.mp4", "frames": 48}],
  "audio": "audio/mix.wav",
  "subtitles": "edit/captions.srt"
}
```

Omit `audio`/`subtitles` if not requested. The helper normalizes/re-encodes clips, removes their audio, pads short clips, adds a prepared audio mix and selectable captions, verifies output frame count and decodes the MP4. It is a finishing helper, not an automatic dialogue/SFX mixer or lip-sync system. Inspect/approve padding and prepare the mix separately. `media.py --help` lists subcommands.
